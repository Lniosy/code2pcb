## v0.1.0 — MVP（当前）

**目标**: 验证核心数据流 代码→HardwareSpec→SchematicDesign→KiCad文件

### 已完成 ✅

- [x] 代码解析器（ESP-IDF/Arduino/Zephyr/MicroPython）
- [x] 自然语言关键词解析（中文+英文）
- [x] 原理图拓扑生成器（MCU最小系统+去耦+外围）
- [x] 基于规则的功能分区布局
- [x] 示意性布线框架
- [x] KiCad .kicad_sch/.kicad_pcb 导出
- [x] MCP Server（6个工具）
- [x] 器件知识库（8个常用器件+LCSC SKU）
- [x] CLI命令（analyze/text2pcb/code2pcb/mcp）
- [x] 项目文档（README/ARCHITECTURE/ROADMAP）
- [x] 测试框架

### 已知限制

- 布线为示意性实现，无实际可用走线
- 文本解析基于关键词，无LLM理解能力
- 引脚级网络连接未实现（网络表为占位）
- 器件库仅8个，需大量扩充

## v0.2.0 — LLM集成

**目标**: 让AI真正理解设计意图，而非仅靠关键词匹配

### 核心功能

- [ ] **LLM器件选型引擎**
  - 输入功能需求 → 输出器件推荐（含替代品、价格、库存）
  - 集成立创商城API实时查询
  - 支持国产器件优先
  
- [ ] **自然语言→原理图**
  - LLM解析复杂描述（如"做一个低功耗的GPS追踪器，每天上报一次位置"）
  - 输出完整的SchematicDesign（含器件、网络、约束）
  
- [ ] **设计约束推理**
  - 从需求描述自动推断设计约束（工作温度、尺寸限制、功耗预算）
  - 自动选择合适的PCB层数、板厚、铜厚

### 技术方案

```python
# LLM驱动的器件选型
class LLMComponentSelector:
    def select(self, requirement: str) -> list[ComponentRecommendation]:
        """
        输入: "需要一个低功耗温湿度传感器，I2C接口，工作温度-40~85°C"
        输出: [
            {"part": "AHT20", "price": "¥2.8", "stock": "50000+", "score": 0.95},
            {"part": "SHT30", "price": "¥5.2", "stock": "12000+", "score": 0.88},
        ]
        """
```

## v0.3.0 — 数据手册引擎

**目标**: 自动从PDF数据手册提取结构化信息，建立器件知识库

### 核心功能

- [ ] **PDF数据手册解析Pipeline**
  - PDF → 表格/文本/引脚图提取
  - 引脚定义自动识别（BGA/QFN/QFP/SOP）
  - 电气参数提取（电压、电流、时序）
  - 推荐应用电路提取
  
- [ ] **典型电路模式库**
  - 50+常见电路模式（电源、接口、射频、保护）
  - YAML格式存储，支持版本管理
  
- [ ] **器件库批量导入**
  - 输入：器件型号列表
  - 自动下载+解析数据手册
  - 输出：结构化ComponentInfo入库

## v2.0.0 — RL智能布线

**目标**: 用强化学习替代规则引擎，实现物理驱动的智能布局布线（对标Quilter）

### 核心功能

- [ ] **GNN布局引擎**
  - 图神经网络建模元件关系
  - 信号分组感知布局
  - 热耦合+机械约束感知
  
- [ ] **RL布线引擎**
  - 强化学习探索多种布线方案
  - 物理驱动（SI/PI约束作为奖励函数）
  - 多方案并行生成+择优
  
- [ ] **EMC风险评估**
  - 基于布局的辐射预测模型
  - 去耦策略优化
  - 关键信号回路面积分析
  
- [ ] **热分析引擎**
  - 功耗密度热点预测
  - 自动热过孔放置
  - 散热路径优化

## v3.0.0 — 全流程自动化

**目标**: 代码→板子一键完成，真正实现AI全流程嵌入式开发

### 核心功能

- [ ] **代码→固件+硬件协同生成**
  - 分析固件代码 → 自动确定引脚分配
  - 固件编译验证 → 确保硬件设计匹配代码
  
- [ ] **DRC自动修复**
  - 发现错误→自动修复→重新验证循环
  - 不再只是报错，而是直接改好
  
- [ ] **多方案探索**
  - 同一需求生成多种方案（不同MCU、不同方案）
  - 成本/面积/功耗多维对比
  
- [ ] **团队协作**
  - Web界面预览设计
  - 版本管理和评审流程
  - 知识积累（组织级设计规范）
